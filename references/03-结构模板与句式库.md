# 肖磊 · 结构模板与句式库

> 配合 `01-风格解剖.md` 使用：01 讲"为什么"，这里给"怎么写"。
> 模板是**结构件**，可复用；模板里举的例句是**内容件**，属于各自的辩题，**绝不能照搬**（见 SKILL.md 红线）。

---

## 一、通用开工流程（任何模式都先走这步）

1. **找参照稿**：打开 `02-原稿全集.md`，按下面的"参照匹配表"挑 1 篇最接近的，精读它的开篇、清场、题眼、收束。
2. **找开篇锚点**：写下一段历史 / 一个人 / 一个被忽略的常识 / 一个自然意象（对应 01 的 ①）。
3. **写题眼句**：`这道题真正的题眼是「___」；它不是「___」，而是「___」。`（⑥）
4. **列清场**：2–3 条现成论证路径，各给正反最强版本 + 一个否定理由（⑤）。
5. **定三层骨架**：三层各一句，逐层更深（⑦⑪）。
6. **配学理与案例**：每层配一条思想史线索（⑧）+ 一个当代落点（②）。
7. **写收束意象**：先想好结尾那个"物"或那句悖论，再倒推全篇（⑫）。

**参照匹配表**：

| 辩题类型 | 推荐参照 |
|---|---|
| 生命/死亡/终极问题 | A01 长生不老、A02 憎恶 |
| 技术/科学/工具理性 | A03 技术中立 |
| 孤独/存在问题 | A04 人终将孤独 |
| 道德/制度/政治 | B01 道德楷模、B03 必要之恶 |
| 言论/媒介/信息 | B02 网络实名制、B09 谣言、B14 大众传媒 |
| 人性/强弱/意义 | B04+B05 人类是强者、B06 这个世界会好 |
| 文明/生存/时间 | B07 给文明以岁月 |
| 苦难/荒谬/幸福 | B08 荒谬应该享受 |
| 隐私/家庭/伦理 | B11 家长查看、B12 人肉搜索、B13 新闻与人伦 |
| 具体政策/民生 | B10 人人都买房 |

## 二、立论长陈词骨架

**母题一：历史演化式**（最常用）
```
[开篇锚点：一个具体年份/事件/意象]
[一辩题关键词的概念分层]
[清场：2–3 条旧路径 + 各配否定理由]
[题眼：这道题真正问的是……]
我方认为……，理由有三：
首先，[第一层：最表层的事实/概念]
其次，[第二层：更深一层的价值/结构]
最后，[第三层：最根本的前提/存在论]
[收束：一个意象或一句悖论]
```

**母题二：正反合式**（A02、A08 一类）
```
[锚点] → 表面看是 A（肉体/规则/表层）→ 其实是 B（精神/意义/深层）→ 追到根上是 C（救赎观/信仰/隐喻）
```

**母题三：概念分层式**（A03、A04、B03 一类）
```
[锚点] → 关键词至少有 N 层：[层1][层2][层3] → 逐层论证 → 第三层收束
```

**母题四：条件递进式**（A01 的后半）
```
即使[最弱条件]成立……；即使[较强条件]成立……；只有在[最强条件]下……
```
（层层加码，把对方逼到只有极端条件才成立）

**母题五：平行对照式**（B02、B05）
```
[自然/历史 A 的兴衰] 与 [辩题对象 B 的兴衰] 平行推进，最后在"同一个道理"上合流
```

**硬要求**：
- 长段落。**禁止一句一段**（立论的大忌）。
- 每层都要有：主张句 → 学理展开 → 当代落地 → 回扣辩题。
- 字数：用户指定从其指定；未指定则 1800–3500 字。

## 三、驳论骨架

1. **给对手的操作命名**（⑰）：`对方从头到尾在做一件事，叫做____。`
2. **拆概念 / 拆逻辑**（⑥⑦⑨）：先问"这个判断是什么性质？"（合理=reasonable 还是 rational？事实还是价值？）
3. **拆语境**：`今天的语境是____，这是一个陷阱，因为……`
4. **给对手的心理/行为找机理**（可给个专名）：`这背后是____（背叛感 / 规训 / 双标 / 消解概念）。`
5. **补足 / 抬升**：`但对方没有谈____，其实……`
6. **收束**：一个意象（星空 / 烛火 / 潮水）。

**风格**：口语、短段、保留现场感（"废话当然自然""我负责任的告诉你"）。口头禅一段最多一两次。

## 四、结辩骨架

1. **设问/现象推进**：`荒谬可以带来幸福 / 苦难 / 荒谬本身……`（B08 式三连）
2. **引一个故事或隐喻**：`这个辩题根本不是____，它是一个隐喻。`（A08）
3. **用隐喻重述立场**：把整场的分歧翻译成这个隐喻里的一种选择。
4. **短句爆发收尾**：不复述立论，要抬高一层。

**要点**：结辩比立论更短、更快、更有画面。可以口语，可以调侃（B08 全年内部梗）。

## 五、哲理辩（"三个故事"）骨架

**核心配方**（A03 / A04 的标准形态）：

```
[开篇：把辩题重问一遍——"当我们在讨论 X 的时候，我们在讨论什么？" + 概念分层]
今天，我有三个故事。
第一个故事，叫「[意象名1]」：
   [从一段真实历史/思想史讲起，引一条思想家谱系，落在"X 是[第一层答案]"上]
   [回扣：这就是我的第一个论点，……这也是我的第一个故事，它叫「[意象名1]」。]
第二个故事，叫「[意象名2]」：
   [更深一层，再引一条思想史线索，落在"X 是[第二层答案]"上]
最后/第三个故事，叫「[意象名3]」：
   [最深的一层，常常是"元层次"——连"中立/答案本身"都要挑战]
   [回到故事的开头] → [收束意象，如"冰，是烫的"]
```

**要点**：
- 每个故事 = **一个概念标签 + 一个意象名字**（黑魔法/白魔法/魔法师；伊萨卡/长安的空气炸锅/冰是烫的）。
- 逻辑走**正—反—合**或**批判—辩护—解构**。
- 三个故事必须指向**同一个结论**的不同层次，不能是三个平行议题。
- 中间可以反复回环：`回到故事的开头`。
- 允许密集内部梗（A04 把同行封为"先生"），但每个梗后要有真论证。

## 六、审题 / 分析问题骨架（M5）

输出四件东西，不必成篇：

1. **题眼候选 1–3 个**：每个说明"它被忽略在哪、重新定义后题变成什么"。
2. **推荐母题**：从上面五选一。
3. **三层骨架**：每层一句话，逐层更深。
4. **可用的学理与案例方向**：各列 2–3 个，标注是否需核实。

**分析任意问题时**（不限于辩论），用同一套：
> 先问"这问题的问法里藏着什么预设"→ 找被偷换的概念 → 拆成层级 → 沿一条思想史线索追问 → 落到一个具体的人和今天 → 收在一个意象上。

## 七、文章 / 演讲 / 随笔骨架（M6）

参照 D01–D03（详见 `05-文章演讲与辩论观.md`）。

- **演讲稿**：先自嘲/破冰（"我就不站在演讲台上说了"）→ 讲自己的故事（具体时间、地点、糗事）→ 提炼出"几个真相"→ 用排比推进 → 落在对听众的呼吁上（不打官腔）。
- **论述随笔**：从一个行业现象切入 → 给一个反常识的判断 → 用"只是，这十年，时代变了"之类的转折推进 → 用鲁迅、古典等收束。
- **散文式随笔**：大量个人叙事先行，观点藏在故事里，结尾轻、准、留白（"这些故事下酒正好"）。

## 八、句式库（结构件，可自由化用）

**开篇（锚点）**
- `从公元前___年的___，到___，关于___，在人类的精神历史上绵延不绝。`
- `___年，___。所以，如果___，___。`
- `当我们在讨论___的时候，我们在讨论什么？`
- `___说："___。"好像很有道理。可是我们再试一下，___。`
- `在美国的___，春天是最美的季节……`（自然意象起手，再平行到辩题对象）

**概念分层**
- `___，我理解至少包括___、___、___。`
- `___至少有 N 层：第一层是___；第二层是___；第三层，是最深的一层，是___。`

**清场**
- `纵观此前的讨论，无非以下观点：第一，___；第二，___；第三，___。`
- `正方会说___；反方也可以说___。但___。我方不愿这样论证。`
- `抛开上述老生常谈，今天的辩题意义何在呢？`

**题眼 / 重定义**
- `我方认为，这道题的题眼，只有一个字，就是"___"。`
- `这道题不是___，而是___。`
- `不要笑话我们咬文嚼字。___告诉我们，___。`
- `这个辩题根本不是___，它是一个隐喻。`

**推进 / 反问**
- `对不对？` / `你信谁？` / `你愿意生活在哪个时代？` / `看到了吗？` / `你看，___。`
- `很简单，___。` / `但问题就在于，___。` / `毕竟，___。`
- `是的，___。` / `我负责任的告诉你，___。`

**命名即定性**
- `对方从头到尾在做一件事，叫做___。`
- `这是所有___的第一步，叫做___；第二步，叫做___。`
- `这背后，是___和___两种力量。`

**收束**
- `我可以放下，但你不能要求。`
- `回到故事的开头。`
- `___，___，___。（三短句排比）`
- `毕竟，___。`（用一个古句收：匹夫无罪，怀璧其罪 / 见诸相非相，即见如来 / 多难兴邦）

> 以上句式为**骨架**。填充时必须换成本辩题的**新意象、新概念、新案例**，不得复用原稿中为该辩题专造的句子。

## 九、口头禅 / 连接词表（节制使用）

| 类别 | 词句 | 频率 |
|---|---|---|
| 主张 | 我方认为、我方坚持、我负责任的告诉你 | 全篇 2–4 次 |
| 确认 | 对不对？ | 哲理辩中密集；其他 ≤3 次 |
| 转折 | 但问题就在于、毕竟、然而 | 自然使用 |
| 推进 | 你看、很简单、是的、看到了吗 | 一段最多 1 次 |
| 收口 | 回到故事的开头、抛开上述老生常谈 | 全篇 1 次 |
| 称呼 | 各位、大家、你、对方辩友、您 | 按场合 |

## 十、交付前自检清单

- [ ] 开篇有**具体锚点**，且锚点与辩题有真实语义关联。
- [ ] 有一个明确的**题眼句**（"题眼是___，不是___，而是___"）。
- [ ] 有**清场**，且给的是对手最强版本、否定理由具体。
- [ ] 三层**逐层更深**，可互换位置即不合格。
- [ ] 学理沿**一条线索**接力，每个引用有**人话翻译 + 当代落点**。
- [ ] 至少一个**能上新闻的当代细节**。
- [ ] 有 1–2 个**换气口**（自嘲/流行文化），且从论证里长出来。
- [ ] 结尾是**意象/悖论**，不是总结、不是口号。
- [ ] 立论是**长段落**，没有一句一段。
- [ ] 通篇没有**编造**的人名/年份/词源/数据。
- [ ] 没有**复刻**原稿为其他辩题专造的意象与金句。
