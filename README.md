## 它是什么

一个「**肖磊腔**」写作与思维引擎。给定辩题、立场、环节，或任意写作 / 表达任务，产出高保真的肖磊式文本：

- 立论长陈词 · 驳论 · 结辩 · 哲理辩（三个故事）
- 演讲 / 随笔 / 长文
- 按他的方式**审题、拆题眼、把一个问题讲到它该有的深度**

它不教你套模板，它教你怎么像他一样**先把题改写成自己出的题，然后答它**。

---

## 核心手法（也是它区别于"AI 腔"的地方）

1. **论域意识**：开篇不定义，先用一个具体历史 / 人物 / 自然意象，把辩题抬进文明尺度。
2. **清场式否定**：把俗见的最强版本请上台，逐条否定（"我方不愿这样论证"），重划战场。
3. **抓题眼**：审人称 / 语态 / 词源，说出"这道题真正的题眼是「___」"。
4. **概念分层 + 思想史谱系**：一个词拆成 2–4 层；思想家沿一条线接力（不是报菜名）。
5. **诗性收束**：结尾凝成一个意象或一句悖论（"冰，是烫的"），不复述、不喊口号。

学理是论据，不是装饰；诗意是准确，不是炫技。

## 看效果（示意）

> **你**：辩题「人终将孤独」，正方，写一篇立论。

> **AI**（节选）：
> 泰戈尔说，孤单是一个人的狂欢，狂欢是一群人的孤单。好像很有道理。可是我们再试一下，长安是一个人的荔枝，荔枝是一群人的长安……今天，我的立论归根结底只有一句话，就是"人"这个概念的建构，就内涵了"孤独"为构成要件。

## 安装

### 方式一：git clone 到本地 skills 目录

```bash
git clone https://github.com/LuYanghao-whaat/xiaolei-debate.git \
  ~/.config/opencode/skills/xiaolei-debate
```

重启 opencode 生效。对话里说一句「用肖磊的风格写一篇立论」就会触发。

### 方式二：作为 skills.sh 兼容包

```bash
npx skills add LuYanghao-whaat/xiaolei-debate
```

## 版本自检

Skill 根目录有 `VERSION`。**用户每次调用本 Skill 前，AI 会先比对本地版本与 GitHub 远程版本**，有新版提示一句；网络失败则静默跳过。

- 远程版本：<https://raw.githubusercontent.com/LuYanghao-whaat/xiaolei-debate/main/VERSION>
- 本地/远程不一致且远程更高时，AI 会问一句是否更新。
